# Social asset manifest

## Files

- `profile-avatar-1080.png`: deterministic 1080×1080 export of the existing app icon.
- `social-key-visual-v1.png`: square launch visual for Instagram, Threads, Facebook, TikTok and community posts.
- `channel-cover-master-v1.png`: wide master cover with the symbol in the right third and typography-safe space on the left.

## Generation mode

The two campaign visuals were generated with the built-in image generation tool using the existing app icon as the brand reference. No CLI fallback was used.

## Final prompt — square key visual

```text
Use case: ads-marketing
Asset type: square social launch key visual
Primary request: elevate the supplied doorway, flame and keyhole app icon into a premium editorial night-time campaign visual for an anonymous human companionship app.
Composition: centered symbol, generous negative space, readable at thumbnail size.
Palette: nocturne navy, deep plum, candle gold, ember and bone cream.
Constraints: no people, faces, romance cues, dating imagery, AI/robot imagery, hearts, app UI, text or watermark.
```

## Final prompt — wide cover

```text
Use case: ads-marketing
Asset type: 16:9 social channel cover
Primary request: extend the approved square campaign mood into a wide cover.
Composition: glowing doorway-candle in the right third; dark negative space on the left for later typography; essential content inside the center safe area.
Palette: nocturne navy, deep plum, candle gold, ember and bone cream.
Constraints: no people, faces, romance cues, dating imagery, AI/robot imagery, hearts, app UI, text or watermark.
```
