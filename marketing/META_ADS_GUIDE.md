## 0. 先講最重要的:現在該花錢打廣告嗎?→ 還不該

- 冷啟動未解 → 就算裝得到,打開**沒人**(火盆會自動開了但不生真人)。
- **現在大砸廣告 = 把陌生人倒進「進不去 / 空的」app,錢直接燒掉,還留壞印象。**

✅ **現在可以做(免費)**:把「帳號 + Pixel + 素材 + 受眾結構」全部備好。
🟡 **可花小錢的唯一理由**:純學習 / 測素材反應(NT$100–200/天當學費),不是為了成長。
🔴 **真正開始投放的三個前提**(全滿足才花大錢,見第 9 節):v23 上線給測試者 → 第一晚機制驗證過 → (若預期上量)Firebase 已在 Blaze。

## 1. 帳號設定(免費,現在就能做)

3. **付款方式**:要投才需綁卡。⚠️ 綁卡=準備花錢,先備好但別急著開 campaign。

## 2. 廣告目標(Objective)— 選錯全盤皆輸
Meta 目標:認知 / 流量 / 互動 / 開發潛在客戶 / **App 推廣** / 銷售。
- ❌ **不要選「App 推廣」**:它優化 app 商店安裝,但你是**封閉 Alpha**(Play 上非公開),導不到封閉測試 → 這目標 Alpha 期用不了。
- ✅ **招募期選「流量(Traffic)」**→ 導到 landing `#join` 報名(你已有 landing + 報名表串 Google Sheet + GA4)。最簡單、直接沿用現有漏斗。
- (未來公開上架後)才換「App 推廣」衝安裝。

## 3. 受眾(Audience)— 最會浪費錢的地方
- 🔴 **只投 Android**:詳細定向 → 裝置/作業系統 = **Android**。你是 Android-only,iPhone 點擊 = 落地也裝不了 = 純浪費 + 挫折。**這條不可省。**
- **地區**:台灣。
- **年齡**:**18+**(你含成人情感/親密話題,且 Meta 政策要求)。
- **興趣定向**:失眠 / 深夜 / 獨處 / 寫日記 / 冥想正念 / 傾訴。⚠️ Meta **限制心理健康類敏感定向**(可能選不到或受限)→ 用「周邊」興趣(失眠、深夜生活、獨處),不要硬戳「憂鬱/焦慮」。
- ❌ **絕不用「約會/交友/單身」興趣**:違背定位,還會把 app 推給「來找對象」的人 → 期待錯位、失望、負評。
- 小預算測試:**窄一點可控**(Android + 台灣 + 18+ + 1–2 興趣);有數據後再放寬,讓 Meta 演算法(Advantage+)去找人。

## 5. 預算 + 出價
- 🔴 **花錢前先確認**:這是你付 Meta 的錢。
- 小測:**NT$100–300/天 × 3–5 天**。每個廣告組跑到有統計意義再判斷,**別每天亂改**(打斷 Meta 學習期)。
- 出價:先用「最高數量 / 最低成本(自動)」,**別一開始手動出價**。
- 看的指標:**CPL(每個報名成本)**。先問自己「一個 Alpha 報名值多少錢」設上限。台灣 traffic→報名 的 CPL 常見 NT$20–80+(視素材/受眾)——小測就是要量出**你的**實際數字。

## 6. 素材 / 文案(on-brand,決定成敗)
視覺用深色燭光系列(`marketing/assets/social-key-visual-v1.png` 風格)。文案守鐵律:**陪伴非約會、無 AI、灰度、誠實**。

### ⚠️ Meta 審核雷區(你這類特別容易中)
- **不要宣稱療效**(「治療/改善 焦慮憂鬱」= 直接拒)。
- **不要斷言/暗示觀看者的狀態**(Meta「個人特徵」政策禁止:不能寫「你是不是很憂鬱?」「感到孤單的你」這種指涉對方)。→ 講**情境**不講**對方**:「有些話想找人說」可以,「你很孤單」不行。
- **不要**「約會/交友/脫單」字眼(你本來就不是,反而安全)。
- 避免性暗示視覺(你是情緒陪伴,守住就好)。

### 廣告文案草稿(可直接 A/B,3 版)
**A｜被聽見**
- 內文:有些話,不是不想說,只是白天沒有適合的地方。/ 一個匿名說說話、被聽見的地方。不是交友,也不是 AI。
- 標題:今晚,有個地方可以說
- CTA:了解詳情

**B｜深夜**
- 內文:深夜還醒著的話,這裡有人陪你待著。不用解釋為什麼,不用「正能量一點」,只是有人聽。
- 標題:匿名 · 只是想被聽見
- CTA:註冊

**C｜樹洞**
- 內文:有些心事,反而只能對不認識的人說。一個可以慢慢說話的地方。
- 標題:說出口,好像就輕了一點
- CTA:了解詳情

> 落地連結全帶 UTM(見下)。CTA 導 landing `#join`。

## 9. 什麼時候才真的開始花錢(決策樹)
```
v23 已上線給測試者? ──否──▶ 先別投(來的人裝不了)
        │是
第一晚機制驗證過?(真人值班+火盆有人)──否──▶ 先別投(來的人撲空)
        │是
預期會上量到幾十上百人同時? ──是──▶ 先確認 Firebase 在 Blaze(否則硬停)
        │
        ▼
NT$100–300/天 小測 3–5 天 → 看 CPL + 報名後有沒有真的留下來
        │
     有效 ──▶ 逐步加預算 / 放寬受眾 / 加轉換優化
     無效 ──▶ 改素材或受眾再測,別加碼
```

> 一句話:**廣告是「放大器」,不是「引擎」。** 先有一個能留住人的晚上(引擎),再用廣告放大。順序反了 = 燒錢。
